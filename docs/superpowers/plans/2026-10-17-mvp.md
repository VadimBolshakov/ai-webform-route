# AI-Chat MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Закрытое веб-приложение чата с AI через OpenRouter: инвайты, вход с 2FA, чат со стримингом, вложения, учёт и лимиты расходов, настройки, админка, страница-ширма; запуск локально в Docker.

**Architecture:** FastAPI-монолит с модулями `auth`, `chat`, `llm`, `files`, `billing`, `account`, `admin`, `notify`, `web`. Страницы рендерятся Jinja2, интерактивность — HTMX, стриминг ответа — `fetch` + `text/event-stream`. PostgreSQL через SQLAlchemy 2 async, миграции Alembic.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, SQLAlchemy 2 (async) + asyncpg, Alembic, pydantic-settings, argon2-cffi, pyotp, segno (QR), cryptography (Fernet), httpx, Jinja2, python-multipart, pypdf, python-docx, Pillow, APScheduler; тесты — pytest, pytest-asyncio, respx. Фронт: htmx, marked, DOMPurify, highlight.js — файлы лежат в `app/web/static/vendor/`, без CDN.

**Spec:** `docs/superpowers/specs/2026-10-17-ai-chat-design.md`

## Global Constraints

- Интерфейс сайта на русском; язык ответа модели — RU/EN из настроек пользователя.
- Секреты только из переменных окружения (`.env`), `.env` не коммитится; в репо — `.env.example`.
- Пароли — Argon2id, минимум 10 символов, проверка по локальному списку утёкших паролей.
- Cookie сессии: имя `__Host-sid`, `HttpOnly`, `Secure`, `SameSite=Strict`, `Path=/`; срок 7 дней, скользящий.
- Все пути `/app/*` без валидной сессии отвечают **404** (не редирект).
- Вход: `/a/{LOGIN_PATH_TOKEN}`; неверный токен — 404.
- Инвайт: одноразовый, срок 48 ч, в БД хранится только SHA-256 токена.
- Месячный лимит по умолчанию $5; алерт при пересечении 80% и 100%; при ≥100% запрос отклоняется.
- Rate-limit чата: 20 запросов в минуту на пользователя.
- Вложения: ≤10 МБ на файл; тип по содержимому; на диск не пишутся; файлы не хранятся, хранится извлечённый текст.
- Стоимость берётся из `usage.cost` ответа OpenRouter, не вычисляется.
- CSP без внешних источников: `default-src 'self'; img-src 'self' data: blob:; style-src 'self'; script-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'self'`.
- Заголовки на всех ответах: HSTS (`max-age=31536000`), `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Permissions-Policy: camera=(), geolocation=(), microphone=()`; на `/a/*` и `/app/*` ещё `X-Robots-Tag: noindex, nofollow` и `Cache-Control: no-store`.
- Текст переписки никогда не передаётся в `Notifier`.
- Время в БД — UTC (`timestamptz`); «месяц» для лимита — календарный месяц UTC.

## Review Focus

1. **Длинная история чата** — старые сообщения отбрасываются по бюджету токенов, но последнее сообщение пользователя уходит всегда, даже если оно одно превышает бюджет. Тест: `test_build_context_keeps_last_user_message_over_budget` (Task 9).
2. **Обрыв стрима (Стоп, закрытая вкладка)** — частичный ответ сохраняется с `interrupted=True`, строка `usage` пишется с `generation_id` и `cost=NULL`, фоновая задача позже дотягивает стоимость. Тесты: `test_stream_disconnect_saves_partial` (Task 11), `test_backfill_costs` (Task 14).
3. **Русские текстовые файлы в cp1251** — декодирование UTF-8, при ошибке cp1251, иначе понятная ошибка. Тест: `test_extract_text_cp1251` (Task 8).
4. **PDF без текстового слоя (скан)** — понятная ошибка «В PDF нет текстового слоя», запрос не отправляется. Тест: `test_extract_pdf_without_text_raises` (Task 8).
5. **HTML/скрипт в ответе модели или в заголовке чата** — на странице истории он экранирован сервером, а клиент рендерит Markdown только через DOMPurify. Тест: `test_chat_page_escapes_message_html` (Task 12).
